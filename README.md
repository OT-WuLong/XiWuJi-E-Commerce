# 栖物集 · Vue 3 商城前端

这是一个学习与作品展示项目：最初跟随公开的“小兔鲜”教学项目逐步实现商城流程，随后独立完善了异常状态、购物车与支付校验、路由守卫、测试和品牌视觉。项目采用 Vue 3、Vite、Pinia、Vue Router 和 Element Plus。

已实现首页、商品分类与详情、登录、购物车、结算、订单列表及支付状态展示。仓库没有自建后端；开发时 `/api` 经 Vite 代理到教学测试接口。

## 本地运行

```sh
npm ci
npm run dev
```

检查代码使用 `npm run lint`，运行测试使用 `npm test`，生产构建使用 `npm run build`。

## 接口地址

默认请求地址是 `/api`。部署静态文件时，需要让部署环境将 `/api` 转发到可用的接口服务；也可以在构建前设置 `VITE_API_BASE_URL` 为允许跨域访问的接口地址。示例见 `.env.example`。`VITE_` 变量会进入浏览器代码，不能放密钥。

搜索、添加地址和部分订单操作尚未实现；页面上不提供会误导用户的可点击入口。支付页面依赖现有测试接口，不执行真实支付验证。
